What is the model looking at, and what should it decide?

These sentences become the TASK line. Be specific about the asset and the decision; the assistant on the right can draft everything from a one-line description.

Completes "Analyze each provided image and …".

What should the model return?

Each field becomes one line of the REQUIRED OUTPUT FORMAT and one attribute on every asset. Put the main classification first and a short justification last.

Both formats are parsed into attributes. JSON is stricter with hosted models; plain lines work well with small local models.

Describe each class with visual indicators

The rubric is what makes grades consistent. Give every option of the main field a name, a one-sentence meaning and 3–5 cues that are visible in the imagery.

Analysis steps and edge cases

Steps tell the model the order to work in. Edge cases say what to answer when the image does not fit any class.
